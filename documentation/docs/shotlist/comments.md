# Comments

Comments can be used to discuss a shot and note down ideas for changes.

## Adding comments

New comments can be created via the shot context menu by selecting "Comment" or using the shortcut `C`.

To create a comment, you need to either be the shotlist's owner or have the "editor" or "commenter" role.

Once a comment exists in a given scene, more comments can be added by simply hovering over a shot and pressing the comment icon on the right-hand side.

Once the comment popover is open, you can type out your comment and send it using the button on the right or the shortcut `Ctrl + Enter`.

When writing comments, you can use a limited subset of Markdown to style them. You can see all the available styling options in the toolbar that opens when you place your cursor in the comment field. You can also hover over these buttons to show their respective shortcuts:

- Bold text: `Ctrl + B`
- Italic text: `Ctrl + I`
- Strikethrough: `Ctrl + Shift + X`
- Unordered list: `Ctrl + Shift + U`
- Ordered list: `Ctrl + Shift + O`
- Quotes: `Ctrl + Q`
- Links: `Ctrl + L`

## Editing comments

Comments can be edited by hovering and clicking the pencil icon. You can only edit your own comments.

If a comment was edited, the text "(edited)" will appear next to the username of the person that wrote it.

## Completing comments

Comments can be marked as completed by any editor or commenter, not just the person that originally left the comment.

Completed comments will no longer be displayed in the comment list, but are not deleted.
