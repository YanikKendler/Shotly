# Navigation

## General

The shotlist is **broken up into scenes**, which are located in the sidebar. When a scene is selected, its shots are loaded and displayed in the table on the right. Scenes are identified by their scene number, the "name" that is displayed in the sidebar is comprised of the scene's attributes, such as the location or time of day.

When viewing a shotlist, four additional icons are displayed in the left sidebar, these open the different tabs of the shotlist settings and allow you to rename the shotlist, edit its attributes, invite collaborators and export it.

!!! Tip
    The shotlist can also be **renamed** by simply clicking the shotlist's name in the top left next to the dashboard icon.

Both shots and scenes can be **modified and reordered** using the 6-dot icon that appears when hovering over either. By clicking and dragging this grip, the scene/shot can be moved and **reordered**. By clicking on the grip, a context menu appears that allows you to **move**, **edit**, or **delete** a scene/shot.

## Keybinds

The shotlist supports the following keybinds:

**General**

- Scenes can be selected using `Alt + [1-9]` (`Alt` + any number from 1 - 9)
- To open the shotlist settings: `Alt + O`
- Open the **Account dialog**: `Alt + A`
- View **Collaboration requests**: `Alt + C`
- Return to the **Dashboard**: `Alt + H`

**Spreadsheet**

- The cells can be navigated using the arrow keys: `↑`, `↓`, `←`, `→`.
- The dropdown menu for single- and multi-selects:
    - can be opened by pressing `Enter`
    - can be navigated using the arrow keys `↑`, `↓`
    - a value can be selected by pressing `Enter`
    - can be closed using `Esc`
- A new shot can be created using `Alt + N`, `Alt + Enter` or `Control + Enter`.
- The context menu for shots can be opened using `Alt + .` and while the menu is open:
    - A [Comment](./comments.md) can be added using `C`
    - The Shot can be deleted using `Del`
    - The Shot can be moved using `↑` or `↓`
    - The Shot Attributes can be edited using `E`

## The save indicator

A save indicator is located in the **bottom right** of the shotlist, most of the time this will be a checkmark (on mobile this indicator is display inside the "?" menu). 

Whenever you make changes to the shotlist it switches to a **spinning circle**, indicating that the changes are being saved. Once the changes are saved, it switches **back to a checkmark**. If there is an error while saving, it switches to a **red exclamation mark**. 

Hovering over the icon will give you **more information** about the current state.
